# Changelog

All notable changes to Chromary are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), adhering to [Semantic Versioning](https://semver.org).

## [1.0.1], Unreleased

### Changed
- **Project renamed: Chroma Forge → Chromary.** One name everywhere, repo, docs, skills,
  playground, MCP server keys, banners, tagline ("the armory of color").
- Brand emoji  → ; refreshed animated banner wordmark and README hero.

## [1.0.0], 2026-10-21

### Added
- **The Vault**: 16 deep dive guides covering 200+ curated color resources
  - REST APIs & MCP, AI agent skills, perceptual color spaces, accessibility (WCAG + APCA),
    design systems & scales, data-viz colormaps, CSS gradients, AI palette generation,
    inspiration & culture, image extraction, libraries & SDKs, print standards,
    color science papers, game/pixel palettes, tool selection matrix, glossary
- **6 AI agent skills** (`SKILL.md` format): `palette-generator`, `contrast-auditor`,
  `theme-builder`, `dataviz-colormaps`, `gradient-smith`, `image-palette`
- **MCP starter**: curated registry + working example MCP server (TypeScript, Bun)
- **9 recipes**: JavaScript (4), Python (2), CSS (3)
- **Live playground**: zero dependency `web/index.html` + GitHub Pages workflow
- Repo meta: README with task-router & badges, CONTRIBUTING, CODE_OF_CONDUCT, MIT LICENSE
