Privacy Policy

Last updated: October 21, 2026. Applies to the chromary website and its GitHub Pages deployment.

Short version: chromary is a static, open source website. It has no accounts, no forms, no analytics, no ads and no cookies of its own. We do not collect, store or sell personal data.

1. Information we collect

Nothing, by design. Browsing this site does not create an account, does not set cookies from us and does not send data to us. There is no server of ours behind this site: pages are served as static files.

2. Third parties involved in delivery

  • GitHub Pages. This site is hosted by GitHub, which may process request logs and related technical data under its own privacy policy. See github.com/site/privacy.
  • Nothing else. Every style, script, font, icon and image on this site is served from this repository itself. The site makes zero requests to third party servers and loads even with the network cut off after the first visit.

3. Cookies and local storage

We set no cookies and use no local storage or session storage. Interactive features (the palette generator, the contrast checker and copytoclipboard buttons) run entirely in your browser and only on your own input.

4. External links and tools

Pages on this site link to third party resources such as color APIs, editors and libraries. Those services are operated by others and are covered by their own privacy policies. We encourage you to review them before use.

5. Data security

Because we collect nothing, there is nothing for us to leak. Any issue affecting the hosting infrastructure is handled by GitHub under its security program.

6. Children

The site is a general audience technical resource and does not knowingly collect any information from anyone, including children.

7. Changes to this policy

If the site ever adds a feature that changes this policy, we will update this page and the date above before that feature ships.

8. Contact

Questions? Open an issue at github.com/izynu/chromary/issues or reach the maintainer at github.com/izynu.
