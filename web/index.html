Agent skill in the open SKILL.md format

A working color library for AI agents.

chromary is a portable skill that helps compatible AI agents research, design, evaluate, and explain color palettes: brand palettes, UI color systems, data visualization sets, and palettes from images. It computes WCAG contrast, builds OKLCH ramps, and exports tokens your project can paste in.

Free and open. The ZIP contains a folder with SKILL.md and its references; extract it into your client's skills directory. See compatibility for per client paths.

Install

Two minutes to a color-engineer agent.

Works with Claude Code, Cursor, Windsurf and any SKILL.md-aware runtime.

1

Install the skills

git clone https://github.com/izynu/chromary.git
mkdir -p .claude/skills
cp -r chromary/skills/* .claude/skills/

Per-project, versioned with your repo. Global install: ~/.claude/skills/ instead. Then just ask naturally: "give me a palette that matches #225C48".

2

Give it live tools (MCP)

cd chromary/mcp/example-color-server
bun install && bun run index.ts

A working stdio MCP server with generate_palette and color_info tools. Full config for Claude Desktop, Cursor & VS Code in the MCP registry.
